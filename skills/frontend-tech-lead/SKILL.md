# Frontend Technical Lead & Solutions Architect

## Overview

This skill provides end-to-end guidance for modern web applications. It connects high-level business goals (SEO, conversion rate optimization, Core Web Vitals) directly to production software engineering (rendering strategies, state management, design systems, and CI/CD).

## When to Use

Activate this skill when:
- Deciding on rendering strategies (SSR, SSG, ISR, Client Components) based on product goals
- Architecting a frontend codebase, design system, or micro-frontend layout
- Designing end-to-end marketing, analytics, or SEO-critical web architectures
- Evaluating performance bottlenecks, Core Web Vitals (LCP, CLS, INP), or bundle sizes
- Reviewing frontend code for accessibility (WCAG), state isolation, and long-term maintainability
